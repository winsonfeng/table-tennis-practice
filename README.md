# 乒乓球 3D 物理模拟 · 落点反解引擎

单文件 Web 应用（`index.html`，HTML + Three.js），无需构建、无需后端，双击即可运行。

**在线体验**：https://winsonfeng.github.io/table-tennis-practice/

## 核心能力

- **物理内核**：重力、空气阻力（Cd≈0.46）、马格努斯力，RK2 积分；台面弹跳用库仑摩擦冲量并与旋转双向耦合（上旋前冲加速、下旋减速）；击球用胶皮抓球模型（切向冲量以"滑移停止"为上限）。
- **落点反解**：在台面点选落点，反解出最佳击球点、击球时机、仰角/偏航、驱动速度、撞击冲量与摩擦冲量，并预测过网余量与落台误差。
- **规则引擎**：必须落台后才能接（禁止截击）、发球第一落点须在本方半台、擦网重发、每 2 分换发。
- **击球定格 · 拍面微距**（`Z` 键）：击球接触瞬间自动暂停并切到拍面微距，可看来球旋转轴与转向、拍面法线与倾角、接触面滑移方向；自动求解"保证落台"的时机/角度/力度，拖动滑块实时重算出球线路，空格放球。
- **拟真人物**：程序化骨架 + 二骨 IK，步法、转腰、挥拍相位、甩腕；支持转播/侧视/俯视/第三人称越肩/第一人称/拍面微距 8 种视角。

## 握拍与手法

- 默认 **中式直拍**：正手攻球 **拍头朝外侧上方**（拍柄斜向内侧下方）；反手默认 **直拍横打**（手腕外展、**拍背朝前**击球），可切换为传统 **推挡**（`B` 键或左侧按钮）。对手为横拍。
- 球打到身体非持拍侧时自动切换为正/反手动作（挥拍方向、转腰、肘位、甩腕方向同步反转）。

## 操作

| 操作 | 说明 |
| --- | --- |
| 鼠标移动 | 控制球拍（"自动迎球"滑块决定自动/手动权重） |
| 左键点击台面 | 指定回球落点 |
| 左/右键拖动 · `Q`/`E` · 滚轮 | 环绕视角 / 缩放 |
| 空格 | 发球；定格中 = 出球继续 |
| `Z` / `X` / `G` / `B` | 定格模式 / 一键最优 / 拍面归零 / 反手横打↔推挡 |
| `W`/`S` · `A`/`D` · `F` · `1~8` | 上步退台 / 左右移动 / 切视角 / 直达视角 |
| `Shift`+拖动（定格中） | 上下=拍面倾角，左右=拍面转向 |

## 本地运行

```bash
git clone https://github.com/winsonfeng/table-tennis-practice.git
open table-tennis-practice/index.html     # 或用任意静态服务器
```

Three.js 从 CDN 加载（带备用源），首次打开需联网。
