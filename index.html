比赛模式（N 键）：11 分制、净胜 2 分、每 2 分换发球。落点自适应——系统按「最可能得分」自动变换进攻落点（深角最难回，胜率高可连续打同一点），也可点击台面临时指定。每板按 力量 / 旋转 / 落点 / 过网 评 S·A·B·C·D 并累计。

击球参数

自动模式（默认）：系统自动迎球 + 按落点反解出最佳时机 / 角度 / 力度。
手动模式（点按钮或按 M）：球拍完全跟鼠标，出球方向与力度只由拍面倾角/转向 + 力度滑块决定，系统不再保证落台，只给预测线路。
拍面是三轴可调的：倾角（负=前倾压拍 / 正=后仰亮拍）、转向（负=左转 / 正=右转）、拍柄方向（绕拍面法线自转，改变拍头 / 拍柄朝向，如朝上 · 朝外 · 朝前；只改姿态，不改变拍面法线与出球）。
定格中 Shift + 左键拖动 调倾角/转向（可大角度自由转）、Shift + 右键拖动 或 Shift + 滚轮 转拍柄方向；G 一键归零。

辅助与对手

球员 · 站位 · 动作

打法风格—
正手：拍头朝外侧上方（拍柄斜向内侧下方），不是举着拍头笔直朝上；反手默认用直拍横打——手腕外展、拍背朝前击球（B 键切换横打 / 推挡）。球打到身体非持拍侧时会自动切成反手动作。
W / S 手动调整站位：S = 退台，W = 上步（也可用上面的滑块）。系统会按来球深浅自动退台。

弧圈对拉 · 退台加质量

对拉状态—
相持中双方连续弧圈时自动进入对拉模式：双方逐步退至中远台，站位随板数后退。加质量：从第3板起逐步提升力量和旋转（每板 +3% 力量 / +4% 旋转，有上限），模拟实战中对拉越拉越转越冲。两个滑块可分别控制退台和加质量的强度（0 = 关闭对应效果）。

发球 随机变化

按真实比赛的上手：下旋＝短而不出台、二跳回旋；反手＝侧下旋·中路；逆旋转＝侧旋从另一侧来；勾手＝手腕勾甩·反向侧拐；急长上旋＝顶底线，逼对手退台。选「随机」则每球变化。发球第一落点必须落本方半台、第二落点落对方半台，擦网判重发。

接发球手段 自动

按来球旋转 / 长短 / 高低自动选择：搓球＝摆短控网（强下旋近网）拧拉＝台内手腕外展包裹，回斜线上旋；挑打＝不转/弱旋转出台时快挑压中路；高调＝强下旋出台时高弧线挂起来的充分上旋。也可以手动锁定一种手段。接发球必须等球在本方半台落台后才能回击，回到台上的第三板起进入相持。

技术 · 拍型（拍头朝向）自动

拍型（拍头朝向 / 甩腕 / 手臂姿态）会按来球与出球参数自动切换：搓球＝拍头朝前、拍面后仰亮开；弧圈＝拍头朝外上、拍面前倾、甩腕薄摩擦；攻球＝拍头朝外上、略前倾；扣杀＝拍头高举下压；推挡/挡球＝拍头朝上、拍面立起。也可以手动锁定一种技术来观察。

击球定格 · 拍面微距 关

怎么用：① 点「定格模式：关」把它切成开（或按 Z）→ 画面顶部出现「定格已开启」；② 按空格/发球开球；③ 球弹到你这半台并被你击中的那一瞬间画面自动暂停、切到拍面微距；④ 拖动时机/力度/摩擦/拍面滑块或点台面改落点，出球线路实时重算；⑤ 按空格或「出球继续」放球。
微距里转视角：按住左键或右键拖动环绕（Q/E 也行）、滚轮缩放；调拍面：Shift+拖动（上下=倾角、左右=转向）或上方「拍面倾角 / 拍面转向」滑块，G 归零。
看不到定格？多半是没碰到球：把上面的「自动迎球」调到 80% 以上（开定格后系统会自动保证迎拍），并且鼠标不要太快乱动；也可以随时点「立即定格」手动冻结在当前击球点。
